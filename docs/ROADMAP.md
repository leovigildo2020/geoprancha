# Próximas melhorias sugeridas

Lista de ideias para desenvolver com o Claude Code. Peça uma por vez, por exemplo: "Implemente o item 1 do docs/ROADMAP.md".

1. **Importar DXF** como camada vetorial (polilinhas, pontos e textos), escolhendo o SRC das coordenadas.
2. **Confrontantes no memorial:** campo por lado do polígono, com o nome do confrontante, incluído no texto.
3. **Exportar memorial em .docx**, já formatado no padrão de peças técnicas.
4. **Coleta GPS com fotos e atributos** em cada vértice ou ponto (usar a câmera do celular via `<input type="file" capture>`).
5. **Área no Sistema Geodésico Local (SGL)**, para comparação com o SIGEF.
6. **Ferramentas de edição:** paralela (offset), buffer, recortar e dividir polígono.
7. **Mapa de localização** (inset) no compositor, com o município ou estado e o imóvel destacado.
8. **Modelos de prancha salvos** (logotipo, carimbo e notas) para reaproveitar entre projetos.
9. **Integração SICAR/CAR:** importar o shapefile do CAR e as camadas de APP e Reserva Legal.
